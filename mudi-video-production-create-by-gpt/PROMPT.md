# Mudi 视频广告制作提示词

## 提交素材

- **必发**　保留原声的原始视频（MP4 或 MOV）和下方提示词。填好产品、条数、优惠或无优惠、声线和交付位置。
- **已有就发**　完整的已批准英文口播。缺指定声线时，附已生成的 WAV 或 MP3。
- **按需发**　可用于广告的配乐或一条参考片。第一次使用时，先在 ChatGPT 对话里选中 **MUDI video production （create by GPT）**。

## 复制到本次制作对话

把方括号里的内容替换成本次信息，空项写“无”或“待确认”。

```text
请使用 MUDI video production （create by GPT），制作 Mudi 的竖屏产品广告。素材是本条附件，或原片目录：[填写路径]。

产品：[例如 Moon Egg RuaRua，灰色]

数量：[1 条 / 2 条]

本次已确认优惠及 CTA：[例如 Black Friday 50% off，Shop Moon Egg；没有就写无]

声音：[例如 03 用 Joanne，04 用 Natasha；两条用不同声线]

参考及指定配乐：[可选]

交付路径：[本地文件夹]，CapCut 工作区或项目：[如有则填]

文案状态：[已有批准稿 / 先审稿 / 我授权你直接定稿]

已批准的英文原稿：[若已有，在这行下面粘贴完整原文]

先检查实际原片的画面和原声。列出能确认的源文件、动作与时码，找出一段可连续使用的正面盘珠，并标记侧面盘珠、手摸珠子、上腕、静态展示及适合做尾镜的位置。一个长视频也按实际动作拆解。

有批准稿就直接使用。需要审稿时，先交每条约 110 个英文词的口播和词数，等我明确确认后再生成正式配音和剪辑。英文品牌名写 Mudi。若本次有已确认的 Black Friday 优惠，让它早一点随口播自然说出，字幕只显示实际口播。

每条竖版 9:16，约 35 秒。单款前三秒内进入带同步原声的正面盘珠，连续保留 5–6 秒。盘珠加速如有必要用1.3–1.4×，珠子原声跟画面一起同步。其他展示镜头通常约 3 秒，按动作与口播切，避免重放素材。同款两条请让文案角度、声线、音乐、镜头顺序和结尾有区别。

旁白保持自然原速和音高，剪掉多余气口，字幕分成贴口播的单行短句，衔接紧密，留白最长 2 秒。按规范使用经确认的字体、字号、阴影和 Reels 安全区，避开产品与界面按钮。音乐有活力但别压过口播或珠声。拨、揉、碰、盘到珠子时保留对应真声，去掉无关背景噪音。检查开头的爆音与闷声。

用可用工具实际剪辑并导出。给我能播放的成片和可继续编辑的 CapCut 项目位置。工程保留独立画面、字幕、配音、音乐和珠串原声，保留口播文本，使我能换声线。若当前缺 CapCut 权限，交付你能实际完成的成片与分轨、字幕和剪点，并写清具体缺项。请报实测片长、每条成片和工程的准确位置，以及你核对过的首个盘珠画面和音轨情况。
```
