# MUDI video production （create by GPT）

A reusable skill for turning Mudi product footage, reference videos, and advertising guides into English ad copy and editable CapCut videos. It covers single-product and collection ads, script approval, shot selection, narration, editable captions, music and bead-contact audio, timeline review, and MP4 verification.

## Install in ChatGPT

1. [Download the skill ZIP](https://github.com/Jingyu1023/mudi-video-production-skill/raw/refs/heads/main/mudi-video-production-create-by-gpt.zip).
2. Open [Skills in ChatGPT](https://chatgpt.com/skills) and select **Add → Upload from your computer**.
3. Select the ZIP as downloaded. Confirm that **MUDI video production （create by GPT）** appears under **Installed**.

## Use it

Choose **MUDI video production （create by GPT）** from the skill picker in a new chat. Open [PROMPT.md](mudi-video-production-create-by-gpt/PROMPT.md), fill in the brief, and paste the prompt with your footage. The same file is available in the installed skill’s **Skill files** list. It also includes a short follow-up to send after approving the script.

An editable CapCut deliverable requires an active environment that can access the footage and operate CapCut. The same skill can prepare copy and an edit plan in a session without CapCut access. The package contains the skill instructions, copyable prompt, and display metadata.
